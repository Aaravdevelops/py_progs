## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system
- pip (Python package manager)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aaravdevelops/py_progs.git
   ```
2. Navigate to the project directory:
   ```bash
   cd py_progs
   ```
3. Run any Python file:
   ```bash
   python filename.py
   ```

## 📖 Usage Examples

### Running a specific program
```bash
python to_do_list.py
```

### Running all programs in sequence
```bash
for file in *.py; do
    echo "Running $file..."
    python "$file"
    echo "------------------"
done
```
